# Benchmark corpus (synthetic)

**Everything in this folder is synthetic.** No document, name, identifier,
address or number here comes from a real person or a real record. The files
are generated by [`../generate_corpus.py`](../generate_corpus.py) with fixed
seeds, so running the script again reproduces them exactly.

| File | Documents | Labelled PII spans | Use |
|---|---:|---:|---|
| `dev.jsonl` | 700 | 1,260 | Finding and fixing errors; tuning thresholds |
| `test.jsonl` | 700 | 1,260 | Reported results (held out) |

Each line is one document:

```json
{"id": "test-0042", "category": "bank", "lang": "en", "text": "...", "spans": [{"start": 16, "end": 35, "type": "card"}]}
```

- `category`: `kyc`, `bank`, `callcentre`, `chat`, `health`, `record` or
  `negative` (documents with no PII at all).
- `lang`: `en`, `hi` (Hindi) or `hinglish`.
- `spans`: every PII span in `text`, with 0-based, end-exclusive character
  offsets and a credgate type. Labels are exact by construction: the
  generator records each span as it inserts the value.

**About the identifiers.** Aadhaar, GSTIN and card numbers are generated to
pass their checksums, because the benchmark has to measure checksum
validation. A random number with a valid checksum can coincide with a real
one by chance; such a coincidence carries no information about any person.
Do not use these values as anonymised data or as test data in production
systems. Email addresses use the reserved `example.com` / `example.org`
domains.
